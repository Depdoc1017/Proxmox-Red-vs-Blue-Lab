# Proxmox Red Team vs. Blue Team Datacenter Lab

This project is a Proxmox-based red team vs. blue team cybersecurity lab designed to simulate a small enterprise datacenter in a controlled virtual environment. The lab was built to demonstrate practical skills in virtualization, network architecture, Windows and Linux administration, remote access validation, defensive monitoring, and incident response documentation.

## Overview
The purpose of this project was to create a realistic enterprise-style lab where cybersecurity concepts could be practiced safely and ethically. The environment included multiple virtual machines, internal networking, and supporting documentation that demonstrated both infrastructure design and security workflow knowledge from attacker and defender perspectives.

## Objectives
- Build a virtualized enterprise-style lab in Proxmox
- Practice system deployment and internal network configuration
- Simulate red team and blue team workflows in a controlled environment
- Validate services, remote access, and core lab functionality
- Document observations, monitoring, and response actions
- Demonstrate hands-on cybersecurity and infrastructure skills

## Environment
- Proxmox virtualization platform
- Windows Server virtual machine
- Kali Linux virtual machine
- Internal virtual networking and bridge configuration
- Remote desktop and service validation workflows
- Monitoring and documentation for defensive analysis

## My Contribution
I designed the lab layout, deployed and configured the virtual machines, organized the network structure, validated connectivity between systems, set up core services, documented workflows, and recorded observations from testing and monitoring activities.

## Lab Highlights
This lab included a Proxmox host running separate Windows Server and Kali Linux virtual machines connected through an internal virtual network. The environment was used to validate virtualization, remote administration, service availability, and defender-side monitoring in a controlled setting.

From the blue team perspective, the project focused on documenting how systems behave, what evidence is generated during administrative and security-related activity, and how that information can support incident response and defensive review.

## Skills Demonstrated
- Virtualization
- Network design
- Windows administration
- Linux administration
- Remote access validation
- Security monitoring
- Incident response documentation
- Troubleshooting and system configuration
